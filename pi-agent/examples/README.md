# Pi CraftOS Agent Examples

This directory contains reference implementations of common tasks in CC: Tweaked. These examples are designed to be Lua 5.1 compatible and follow the API definitions provided in `.pi-agent/docs/`.

## How to Use

The Pi agent can be prompted to "Implement a [task] similar to the example in `examples/[filename].lua`" to ensure consistent styling and API usage.

## Categories

- **Filesystem & OS**: (`01_fs_backup.lua`)
- **Hardware & Redstone**: (`02_redstone_toggle.lua`)
- **Networking**: (`03_rednet_chat.lua`, `06_http_request.lua`)
- **Environment & Positioning**: (`04_gps_locate.lua`)
- **Concurrency**: (`05_parallel_input.lua`)
